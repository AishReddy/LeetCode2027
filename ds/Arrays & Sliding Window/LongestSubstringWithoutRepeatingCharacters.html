3. Longest Substring Without Repeating Characters

LeetCode Medium — Sliding Window + HashSet

O(n) time  |  O(min(n,m)) space
Problem

Given a string s, find the length of the longest substring without repeating characters.

⚡ Brute force checks every substring pair in O(n²) or O(n³). The Sliding Window shrinks and expands a window in a single O(n) pass — each character is added and removed from the set at most once.
Approach — Sliding Window + HashSet
1
Initialise: left = 0, max_sum = 0, empty setOfCharacters. The window is [left … right].
2
Expand right: Move right one step. If s.charAt(right) is already in setOfCharacters, shrink from the left — remove s.charAt(left) and advance left++ — until the duplicate is gone.
3
Add & measure: Add s.charAt(right) to the set. Compute length = right - left + 1. Update max_sum if length is greater.
4
Return max_sum after the loop ends.

Complexity Analysis
Time Complexity
O(n)
Each character is visited by right once and removed by left at most once — so at most 2n operations total.
Space Complexity
O(m)
setOfCharacters holds at most min(n, m) characters, where m is the size of the character set (e.g. 26 for lowercase letters, 128 for ASCII).
Why O(n) and not O(n²)? — Even though there's a while loop inside the for loop, left only ever moves forward. It can advance at most n times total across all iterations — so the inner loop doesn't multiply the cost.

Why HashSet? — O(1) average-case contains, add, and remove. This keeps each window operation constant time.
Java Solution — Your Code
class Solution {
    public int lengthOfLongestSubstring(String s) {
        int left    = 0;
        int length;
        int max_sum = 0;
        Set<Character> setOfCharacters = new HashSet<Character>();

        for (int right = 0; right < s.length(); right++) {

            // shrink window until s[right] is not a duplicate
            while (setOfCharacters.contains(s.charAt(right))) {
                setOfCharacters.remove(s.charAt(left));
                left++;
            }

            setOfCharacters.add(s.charAt(right));  // expand window
            length  = right - left + 1;             // current window size
            if (max_sum < length)
                max_sum = length;                    // update global best
        }

        return max_sum;
    }
}
Key Insight
The window [left … right] always contains only unique characters — guaranteed by the while loop that evicts from the left before inserting on the right.

length = right − left + 1
Because left never moves backward, the total number of removals across all iterations is at most n — giving amortised O(1) per step and O(n) overall.
