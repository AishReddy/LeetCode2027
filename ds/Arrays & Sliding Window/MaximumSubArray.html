53. Maximum Subarray

LeetCode Medium — Kadane's Algorithm

O(n) time  |  O(1) space
Problem

Given an integer array nums, find the contiguous subarray (containing at least one number) which has the largest sum, and return that sum.

⚡ Brute force checks every subarray in O(n²). Kadane's algorithm does it in a single O(n) pass by making one greedy decision at each index.
Approach — Kadane's Algorithm
1
Initialise: Set maxSum = 0 (running window sum) and max = Integer.MIN_VALUE (global best). Using MIN_VALUE ensures all-negative arrays are handled correctly.
2
Extend then check: For every element, first maxSum += nums[j] (always extend), then update max = Math.max(max, maxSum).
3
Reset negative prefix: If maxSum < 0, reset maxSum = 0 — a negative running sum can only drag down future subarrays, so we discard it and start fresh. Return max at the end.

Complexity Analysis
Time Complexity
O(n)
Single pass through the array. One comparison and one update per element. No nested loops.
Space Complexity
O(1)
Only two integer variables — maxSum (running window) and max (global best). No auxiliary data structures.
Why not O(n²)? — Brute force checks every pair (i, j) and computes subarray sums. Kadane's eliminates recomputation by carrying a running sum maxSum and resetting it whenever it goes negative.
Why greedy works: If maxSum < 0 after adding nums[j], the accumulated prefix is a liability — any future subarray starting after j is guaranteed to be better without it.
Java Solution — Your Code
class Solution {
    public int maxSubArray(int[] nums) {

        // ── Brute Force O(n²) ─────────────────────────────────
        /*
        int max = Integer.MIN_VALUE;
        for (int i = 0; i < nums.length; i++) {
            int sum = 0;
            for (int j = i; j < nums.length; j++) {
                sum = sum + nums[j];
                max = Math.max(sum, max);
            }
        }
        return max;
        */

        // ── Kadane's O(n) ─────────────────────────────────────
        int maxSum = 0;                     // running subarray sum
        int max    = Integer.MIN_VALUE;     // global best (handles all-negative)

        for (int j = 0; j < nums.length; j++) {
            maxSum += nums[j];                  // extend current window
            max = Math.max(max, maxSum);       // update global best

            if (maxSum < 0) {
                maxSum = 0;                   // negative prefix → reset window
            }
        }
        return max;
    }
}
