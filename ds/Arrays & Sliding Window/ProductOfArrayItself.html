238. Product of Array Except Self

LeetCode Medium — Prefix × Suffix approach

O(n) time  |  O(1) extra space
Problem

Given an integer array nums, return an array output such that output[i] is equal to the product of all elements of nums except nums[i]. You must solve it without division and in O(n).

⚡ Division trick (total product ÷ nums[i]) fails when a zero exists in the array.
Approach — Two-Pass Prefix/Suffix
1
Prefix pass (left → right): Build the output array where output[i] = product of every element to the left of index i. Start with 1 as the running product.
2
Suffix pass (right → left): Traverse again keeping a running suffix product. Multiply output[i] by suffix, then update suffix with nums[i]. No extra array needed — output holds the final answer in place.
3
Result: output[i] = (prefix product of left side) × (suffix product of right side) = product of all elements except nums[i].

Complexity Analysis
Time Complexity
O(n)
Two linear passes over the array (prefix + suffix). No nested loops. Total = 2n → O(n).
Space Complexity
O(1)
Output array doesn't count as extra space per problem convention. Only one integer (suffix) is used as auxiliary memory.
Why not O(n²)? — A brute-force nested loop multiplying all other elements for each index is O(n²). The prefix/suffix trick avoids recomputation by storing partial products.
Why not O(n) space? — A naive approach uses two separate arrays (prefix[] and suffix[]). Here, the suffix is maintained as a single running variable multiplied directly into the output array in the second pass.
Key Insight
For every index i, the answer is:
output[i] = prefix[i]  ×  suffix[i]
where prefix[i] = product of nums[0..i-1] and suffix[i] = product of nums[i+1..n-1]. Computing these two running products with two passes avoids any division and handles zeros naturally.
Java Solution
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] output = new int[n];

        // Pass 1: fill output with prefix products
        int prefix = 1;
        for (int i = 0; i < n; i++) {
            output[i] = prefix;
            prefix *= nums[i];
        }

        // Pass 2: multiply suffix products in-place
        int suffix = 1;
        for (int i = n - 1; i >= 0; i--) {
            output[i] *= suffix;
            suffix *= nums[i];
        }

        return output;
    }

    // Driver
    public static void main(String[] args) {
        Solution sol = new Solution();
        int[] result = sol.productExceptSelf(new int[]{1, 2, 3, 4});
        System.out.println(Arrays.toString(result)); // [24, 12, 8, 6]
    }
}
