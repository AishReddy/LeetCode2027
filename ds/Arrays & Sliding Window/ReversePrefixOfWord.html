2000. Reverse Prefix of Word

LeetCode Easy — Find + Two-Pointer Reverse

easy O(n) time  |  O(n) space
Problem

Given a string word and a character ch, reverse the segment of word from index 0 up to and including the first occurrence of ch. If ch is not in the word, return the word unchanged.

word = "abcdefd", ch = 'd'
First 'd' at index 3 → reverse [0..3] = "abcd" → "dcba"
Result: "dcba" + "efd" = "dcbaefd"
⚡ Two steps: find the first occurrence of ch using indexOf, then reverse the prefix using a two-pointer swap.
Approach — indexOf + Two-Pointer Reverse
1
Find: int idx = word.indexOf(ch). If idx == -1 → return word unchanged.
2
Convert: char[] arr = word.toCharArray() — strings are immutable in Java, so we need a char array to swap in-place.
3
Two-pointer reverse with left=0, right=idx. Swap arr[left] and arr[right], then left++, right-- until they cross.
4
Return new String(arr).
Walkthrough   word = "abcdefd", ch = 'd'
Step 1 — indexOf('d') = 3
Step 2 — Two-pointer reverse [0..3]
left right swap arr after
Complexity Analysis
Time Complexity
O(n)
indexOf scans at most n chars. Reverse swaps at most idx/2 ≤ n/2 pairs. Total O(n).
Space Complexity
O(n)
toCharArray() creates a copy of the string — O(n). Needed because Java strings are immutable.
Why toCharArray()? Java strings are immutable — you can't modify word.charAt(i) in place. Converting to char[] lets us swap characters directly.

Why left < right (not ≤)? When left == right we're at the middle element — no swap needed. Using < skips it correctly for both odd and even length prefixes.
Java Solution
class Solution {
    public String reversePrefix(String word, char ch) {
        int idx = word.indexOf(ch);
        if (idx == -1) return word;   // ch not found

        char[] arr = word.toCharArray();

        int left  = 0;
        int right = idx;

        while (left < right) {
            char temp  = arr[left];
            arr[left]  = arr[right];
            arr[right] = temp;
            left++;
            right--;
        }

        return new String(arr);
    }
}
Pattern to remember
1. indexOf(ch) → find boundary, handle -1
2. toCharArray() → make mutable
3. Two-pointer swap: left=0, right=idx, swap while left < right
4. new String(arr) → return
Key Insight
This is just a standard two-pointer reverse applied to a substring. The only twist is finding the right boundary with indexOf.
a b c d e f d
↑           ↑
left=0    right=3 → swap → d b c a → swap again → d c b a
The rest of the string [idx+1..] is untouched.
