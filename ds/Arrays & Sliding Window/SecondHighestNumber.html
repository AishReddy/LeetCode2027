Second Highest Number

Single Pass — Track max and secondMax simultaneously

O(n) time  |  O(1) space
Problem

Given an integer array nums, return the second highest distinct value. If no valid second maximum exists, return Integer.MIN_VALUE.

⚡ Track two variables simultaneously in one pass. The key is the update order — secondMax must be updated before max, and duplicates of max must be skipped.
Approach — Single Pass with Two Variables
1
Init: both max and secondMax start at Integer.MIN_VALUE.
2
New overall max: if num > max → set secondMax = max first, then max = num. Order matters — don't lose the old max.
3
Better secondMax: else if num > secondMax && num != max → update secondMax = num. The num != max guard handles duplicates.
4
Return secondMax.

Edge Cases
[5, 5, 5] — all duplicates
secondMax stays MIN_VALUE because num != max guard blocks every update.
[5] — single element
secondMax stays MIN_VALUE — no second distinct element exists.
[5, 5, 3] — leading dup
5 sets max. Second 5 is skipped (num != max). 3 > MIN → secondMax = 3. ✓
[1, 2] — two elements
1 → max=1. 2 > max → secondMax=1, max=2. Returns 1. ✓
Complexity Analysis
Time Complexity
O(n)
Single pass — every element visited exactly once. No sorting.
Space Complexity
O(1)
Only two integer variables — max and secondMax.
Your Java Solution
public int secondHighest(int[] nums) {
    int max       = Integer.MIN_VALUE;
    int secondMax = Integer.MIN_VALUE;

    for (int num : nums) {
        if (num > max) {
            secondMax = max;   // old max becomes secondMax first
            max       = num;   // then update max
        } else if (num > secondMax && num != max) {
            secondMax = num;   // better secondMax (not a dup of max)
        }
    }

    return secondMax;
}
3 things to remember
1. Init both to Integer.MIN_VALUE — handles negative numbers
2. Update secondMax = max before max = num — order matters
3. num != max guard — prevents duplicates from becoming secondMax
Key Insight
Three mutually exclusive cases for each number:
num > max               → new overall max
num > secondMax && num != max → new secondMax
otherwise                → ignore
The else if ensures these are mutually exclusive — if num beats max, we don't also try to update secondMax with the same num.
