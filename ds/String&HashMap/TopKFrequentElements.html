347. Top K Frequent Elements

LeetCode Medium — HashMap + Bucket Sort

medium O(n) time — no sorting!
Problem

Given an integer array nums and an integer k, return the k most frequent elements. You may return the answer in any order.

⚡ A heap/sort approach is O(n log n). Bucket Sort uses the fact that frequency is bounded by n — giving true O(n).
Approach — HashMap + Bucket Sort
1
Count frequencies: Build Map<Integer,Integer> freqMap — for each number, count how many times it appears.
2
Bucket by frequency: Create List<Integer>[] bucket of size n+1. Index = frequency. Put each number into bucket[freq]. Max frequency can't exceed n, so the array is always big enough.
3
Collect top k: Scan buckets from high index → low (highest frequency first). Add elements to result until you have k elements.
4
Return the result array.
Walkthrough   nums = [1,1,1,2,2,3], k = 2

Step 1 — freqMap:  1→3, 2→2, 3→1

Step 2 — Buckets (index = frequency, size = n+1 = 7):

Step 3 — Scan from right, collect k=2:  bucket[3]=[1] → take 1  |  bucket[2]=[2] → take 2  |  done.

✅  result = [1, 2]
Complexity Analysis
Time Complexity
O(n)
Counting = O(n). Building buckets = O(n). Scanning buckets = O(n). No sorting anywhere.
Space Complexity
O(n)
freqMap holds at most n entries. bucket array is size n+1. Result is size k ≤ n.
Why bucket size n+1? The maximum possible frequency of any element is n (if all elements are the same). So indices 0..n cover all possible frequencies.

vs. Heap approach O(n log k): A min-heap of size k is cleaner to code but slower. Bucket sort wins when you need true O(n).
Java Solution
class Solution {
    public int[] topKFrequent(int[] nums, int k) {

        // Step 1: count frequencies
        Map<Integer, Integer> freqMap = new HashMap<>();
        for (int n : nums)
            freqMap.put(n, freqMap.getOrDefault(n, 0) + 1);

        // Step 2: bucket sort — index = frequency
        List<Integer>[] bucket = new List[nums.length + 1];
        for (int num : freqMap.keySet()) {
            int freq = freqMap.get(num);
            if (bucket[freq] == null)
                bucket[freq] = new ArrayList<>();
            bucket[freq].add(num);
        }

        // Step 3: collect top k from high frequency → low
        int[] result = new int[k];
        int idx = 0;
        for (int i = bucket.length - 1; i >= 0 && idx < k; i--) {
            if (bucket[i] == null) continue;
            for (int num : bucket[i]) {
                result[idx++] = num;
                if (idx == k) break;
            }
        }

        return result;
    }
}

Key Insight
Frequency is bounded by n — no element can appear more than n times. So instead of sorting by frequency (O(n log n)), use the frequency itself as an array index — O(n).

bucket[1] = [3]   ← appears 1 time
bucket[2] = [2]   ← appears 2 times
bucket[3] = [1]   ← appears 3 times ★ top
