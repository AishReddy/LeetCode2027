242. Valid Anagram

LeetCode Easy — Frequency Count with int[26]

O(n) time  |  O(1) space
Problem

Given two strings s and t, return true if t is an anagram of s, and false otherwise. An anagram uses exactly the same characters the same number of times.

⚡ Sorting both strings is O(n log n). Counting frequencies is O(n) with O(1) space — always prefer this for lowercase-only problems.
Approach — Frequency Count with int[26]
0
Early exit: If s.length() != t.length() return false immediately. Different lengths can never be anagrams.
1
Count s: For each char in s, increment sa[c - 'a']++. The trick c - 'a' maps 'a'→0, 'b'→1 … 'z'→25.
2
Count t: Same process for t into ta[].
3
Compare: Loop i = 0..25. If any sa[i] != ta[i] → return false. If all match → return true.

Complexity Analysis
Time Complexity
O(n)
Three loops — each O(n), O(n), O(26). The comparison loop is always exactly 26 iterations regardless of input size.
Space Complexity
O(1)
sa[26] and ta[26] are fixed-size arrays. Size never changes with input — always exactly 52 integers.
Unicode follow-up: If the problem allows Unicode (not just lowercase letters), int[26] breaks. Switch to HashMap<Character, Integer> — same idea, O(n) time but now O(k) space where k is the unique character count.

The - 'a' trick: Characters in Java are just numbers. 'a' = 97, 'b' = 98 … 'z' = 122. Subtracting 'a' (97) maps each char to an index 0–25.
Java Solution — Your Code
class Solution {
    public boolean isAnagram(String s, String t) {

        // early exit — different lengths can never be anagrams
        if (s.length() != t.length()) return false;

        int[] sa = new int[26];   // frequency count for s
        int[] ta = new int[26];   // frequency count for t

        for (int i = 0; i < s.length(); i++)
            sa[s.charAt(i) - 'a']++;

        for (int i = 0; i < t.length(); i++)
            ta[t.charAt(i) - 'a']++;

        for (int i = 0; i < sa.length; i++)
            if (sa[i] != ta[i]) return false;

        return true;
    }
}
Key Insight
Two strings are anagrams if and only if their character frequency arrays are identical.
sa[c - 'a']++  maps any lowercase char to index 0–25
The comparison loop is always exactly 26 iterations — constant time regardless of string length. That's why space is O(1).

If asked about Unicode: replace int[26] with HashMap<Character,Integer>.
