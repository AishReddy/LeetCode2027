Easy Array Hash Set LeetCode #217

Contains Duplicate / Java

Given an integer array, return true if any value appears at least twice, or false if every element is distinct.

Problem Statement

Given an integer array nums, return true if any value appears at least twice, and false if every element is distinct.

Example 1
Input: [1, 2, 3, 1]
Output: true
1 appears at index 0 and 3.
Example 2
Input: [1, 2, 3, 4]
Output: false
All elements are distinct.
Example 3
Input: [1, 1, 1, 3, 3, 4, 3, 2, 4, 2]
Output: true
Multiple duplicates exist.
Approaches

Brute Force

Compare every pair of elements with nested loops. If nums[i] == nums[j] for any i != j, return true.

Time O(n²) Space O(1)

Sort First

Sort the array, then check adjacent elements. Duplicates will be neighbours after sorting. One linear scan after sorting.

Time O(n log n) Space O(1)

Hash Set

Stream through the array, adding each value to a HashSet. If a value is already present, a duplicate is found instantly.

Time O(n) Space O(n)
Solution Code
ContainsDuplicate.java 
import java.util.HashSet;
import java.util.Set;

class Solution {

    /**
     * Returns true if any value appears at least twice.
     * Time  : O(n)  — single pass; HashSet add/contains are O(1) average
     * Space : O(n)  — HashSet stores at most n distinct elements
     */
    public boolean containsDuplicate(int[] nums) {
        Set<Integer> seen = new HashSet<>();

        for (int num : nums) {
            if (!seen.add(num)) {   // add() returns false if already present
                return true;
            }
        }

        return false;
    }
}
How It Works
1

Create a HashSet

Initialise seen as a Set<Integer>. A HashSet stores unique values only and provides O(1) average time for both add and contains via hashing.

2

Iterate with a for-each loop

Visit every element num in nums exactly once. The loop exits early the moment a duplicate is found — no wasted work.

3

Use add() return value as a free check

HashSet.add(e) returns true if the element was newly inserted, or false if it was already present. We exploit this to combine the membership check and insertion into one O(1) call — no separate contains() needed.

4

Return true on first duplicate

If add() returns false, the value was already in the set — we have found a duplicate. Return true immediately. No need to scan the rest of the array.

5

Return false after full scan

If the loop completes without any duplicate, every element was unique. Return false. The set now holds all n distinct values.

Single pass through the array. Each HashSet.add() is O(1) amortised. Total work is proportional to n.

Time — Worst
O(n)

All elements are distinct (return false) — the full array is scanned. Still linear; no nested loops anywhere.

Space
O(n)

In the worst case (no duplicates) the HashSet holds all n elements. Each integer occupies O(1), so total space is O(n).

Sort approach
O(n log n)

Sorting takes O(n log n) but uses O(1) extra space. Trade-off: slower time, better memory than HashSet solution.

Brute force
O(n²)

Nested loops check all n×(n−1)/2 pairs. Fine for tiny arrays, impractical for n > 10,000.

Edge Cases

All distinct

Every element is unique. The full array is scanned, the set grows to size n, and false is returned at the end.

Input: [1, 2, 3, 4] → false

Duplicate at start

Best case — the second element equals the first. add() returns false on the very first attempt, returning true instantly.

Input: [5, 5, 6, 7] → true

Duplicate at end

Worst case — the duplicate is the very last element. The entire array is traversed before the duplicate is found.

Input: [1, 2, 3, 4, 1] → true

Single element

Only one element — no pair can exist. The loop runs once, add() succeeds, the loop ends, returns false.

Input: [42] → false

All same value

Every element is identical. Duplicate found on the second iteration — O(1) effective runtime in this input.

Input: [7, 7, 7, 7] → true

Negative numbers

HashSet handles negatives naturally — integer hashing works for all int values including negatives.

Input: [-1, -2, -3, -1] → true
