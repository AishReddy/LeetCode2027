21. Merge Two Sorted Lists

LeetCode Easy — Dummy Node + Two Pointers

easy O(n+m) time  |  O(1) space
Problem

Given the heads of two sorted linked lists list1 and list2, merge them into one sorted linked list and return its head. Merge by splicing existing nodes — no new nodes.

⚡ Use a dummy head node to simplify edge cases — no special handling for the first node. The real result starts at dummy.next.
Approach — Dummy Node + Two Pointers
1
Create dummy node: ListNode dummy = new ListNode(0). Keep a curr pointer at dummy — we'll attach nodes here.
2
Compare heads: while both lists have nodes, compare list1.val vs list2.val. Attach the smaller one to curr.next and advance that list's pointer.
3
Attach remainder: when one list is exhausted, attach the remaining nodes of the other directly — they're already sorted.
4
Return dummy.next — the head of the merged list.

Complexity Analysis
Time Complexity
O(n+m)
Every node from both lists is visited exactly once. n = length of list1, m = length of list2.
Space Complexity
O(1)
Only the dummy node and a few pointers. No new nodes are created — existing nodes are re-linked.
Why dummy node? Without it you'd need to handle "what is the first node of the result?" as a special case. The dummy lets curr.next = ... work uniformly from the start.

Why not create new nodes? We just re-wire the next pointers of existing nodes — O(1) space instead of O(n+m).
Java Solution
class Solution {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        ListNode dummy = new ListNode(0);  // dummy head
        ListNode curr  = dummy;

        while (list1 != null && list2 != null) {
            if (list1.val <= list2.val) {
                curr.next = list1;
                list1     = list1.next;
            } else {
                curr.next = list2;
                list2     = list2.next;
            }
            curr = curr.next;
        }

        // attach remaining nodes
        curr.next = (list1 != null) ? list1 : list2;

        return dummy.next;
    }
}
4 things to remember
1. Dummy: ListNode dummy = new ListNode(0); ListNode curr = dummy;
2. Compare: list1.val <= list2.val → attach list1, advance list1
3. Tail: curr.next = (list1 != null) ? list1 : list2
4. Return: dummy.next
Key Insight
The dummy node is a sentinel — it has no real value but gives curr something to point to before the first real node is picked. This eliminates the need to special-case the head of the result.

After the while loop, at least one list is null. The other (if non-null) is already sorted and just needs to be attached — one line instead of another loop.
