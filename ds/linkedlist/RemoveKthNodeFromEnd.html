19. Remove Nth Node From End of List

LeetCode Medium — Dummy Node + Two Pointers (gap of k)

medium O(n) time  |  O(1) space
Problem

Given the head of a linked list, remove the kth node from the end and return the head of the modified list.

list = [1, 2, 3, 4, 5], k = 2
Remove 4 (2nd from end) → [1, 2, 3, 5]
⚡ Key trick: move fast pointer k steps ahead of slow. When fast reaches null, slow is right before the node to remove.
Approach — Dummy + Two Pointers (k-gap)
1
Dummy node: create dummy.next = head. Start both slow and fast at dummy. Dummy handles the edge case of removing the head node.
2
Advance fast k+1 steps from dummy (or k steps from head). Now fast is exactly k+1 nodes ahead of slow — a gap of k.
3
Move both together until fast == null. Now slow points to the node just before the one to remove.
4
Delete: slow.next = slow.next.next. Return dummy.next.
Why k+1 steps from dummy (not k from head)?
We want slow to land on the node before the target — so we can do slow.next = slow.next.next. Starting from dummy and moving fast k+1 steps achieves this gap precisely.
Walkthrough   [1,2,3,4,5], k=2
Phase 1 — advance fast k+1=3 steps from dummy
Phase 2 — move both until fast=null
Phase 3 — slow.next = slow.next.next
Complexity Analysis
Time Complexity
O(n)
One pass. fast travels n steps total (k+1 in phase 1, n-k-1 in phase 2). slow travels n-k-1 steps.
Space Complexity
O(1)
Only dummy, slow, fast pointers. No extra data structures.
Why dummy node? If k equals the list length, we'd remove the head. Without dummy, slow would have nowhere to start — dummy gives slow a valid "before head" position so slow.next = slow.next.next always works.
Java Solution
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        ListNode dummy = new ListNode(0);
        dummy.next = head;

        ListNode slow = dummy;
        ListNode fast = dummy;

        // advance fast n+1 steps ahead of slow
        for (int i = 0; i <= n; i++)
            fast = fast.next;

        // move both until fast is null
        while (fast != null) {
            slow = slow.next;
            fast = fast.next;
        }

        // slow is just before the target node
        slow.next = slow.next.next;

        return dummy.next;
    }
}
Pattern to remember
1. Dummy: dummy.next=head; slow=fast=dummy
2. Gap: for i=0 to n: fast=fast.next (n+1 steps)
3. Move: while fast!=null: slow=slow.next, fast=fast.next
4. Delete: slow.next = slow.next.next
5. Return: dummy.next
Key Insight
Maintaining a gap of k+1 between fast and slow means: when fast reaches null (past the last node), slow is exactly at the node before the kth from end.
dummy → 1 → 2 → 3 → 4 → 5 → null
slow points to 3, fast=null → delete 4
