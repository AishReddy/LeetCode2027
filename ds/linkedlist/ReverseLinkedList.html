206. Reverse Linked List

LeetCode Easy — Three Pointers (prev, curr, next)

easy O(n) time  |  O(1) space
Problem

Given the head of a singly linked list, reverse the list and return the new head.

Input: 1 → 2 → 3 → 4 → 5 → null
Output: 5 → 4 → 3 → 2 → 1 → null
⚡ You can't go back in a singly linked list. Use three pointers — prev, curr, next — to flip one arrow at a time without losing your place.
Approach — Three Pointers
1
Init: prev = null, curr = head.
2
Save next: next = curr.next — save the forward pointer before overwriting it.
3
Flip arrow: curr.next = prev — point current node backward instead of forward.
4
Advance: prev = curr, curr = next. Repeat until curr == null. Return prev — the new head.
Walkthrough   [1 → 2 → 3 → 4 → 5]
step prev curr next action
Complexity Analysis
Time Complexity
O(n)
Single pass — every node is visited exactly once.
Space Complexity
O(1)
Only three pointers — prev, curr, next. No extra data structures.
Why save next first? curr.next = prev overwrites the forward pointer. If you haven't saved next first, you lose your way through the rest of the list.

Why return prev not curr? When the loop ends, curr == null. prev is the last real node — the new head.
Java Solution
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode prev = null;
        ListNode curr = head;

        while (curr != null) {
            ListNode next = curr.next;   // 1. save next
            curr.next    = prev;         // 2. flip arrow
            prev         = curr;         // 3. advance prev
            curr         = next;         // 4. advance curr
        }

        return prev;   // new head
    }
}
4 lines inside the loop — in order
1. next = curr.next   save
2. curr.next = prev   flip
3. prev = curr        advance prev
4. curr = next        advance curr
Key Insight
At every step, nodes to the left of curr are already reversed. prev is the head of that reversed portion.
Before: null ← 1 ← 2   curr=3 → 4 → 5
After flip: null ← 1 ← 2 ← 3   curr=4 → 5
The order of the 4 lines matters — if you advance curr before saving next, the list is lost forever.
