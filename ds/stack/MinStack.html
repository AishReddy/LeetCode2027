155. Min Stack

LeetCode Medium — Two Stacks

medium O(1) all operations
Problem

Design a stack that supports push, pop, top, and getMin — all in O(1) time.

⚡ The challenge is getMin() in O(1). A single stack can't do this without scanning. Solution: maintain a second "min stack" that tracks the minimum at every level.
Approach — Two Stacks
1
Two stacks: stack — stores all values normally. minStack — stores the current minimum at each level.
2
push(val): always push to stack. Push to minStack only if it's empty or val <= minStack.peek() — i.e. a new minimum.
3
pop(): always pop stack. Pop minStack only if minStack.peek().equals(popValue) — the removed value was the current minimum. Use .equals() not ==.
4
getMin(): just return minStack.peek() — always O(1).

operation stack after minStack after return
Complexity Analysis
Time Complexity
O(1)
All four operations — push, pop, top, getMin — are O(1). No scanning or sorting.
Space Complexity
O(n)
Two stacks each of size n. minStack stores one entry per push — same size as main stack.
Why store min at every level? When you pop a value that happened to be the minimum, you need to know what the new minimum is instantly. Storing the running minimum at each stack level gives you that in O(1).

Key invariant: minStack.peek() always equals the minimum of all values currently in stack.
Java Solution
class MinStack {
    private Stack<Integer> stack;
    private Stack<Integer> minStack;

    public MinStack() {
        stack    = new Stack<>();
        minStack = new Stack<>();
    }

    public void push(int val) {
        stack.push(val);
        // only push to minStack if val is a new minimum
        if (minStack.isEmpty() || val <= minStack.peek())
            minStack.push(val);
    }

    public void pop() {
        int popValue = stack.pop();
        // only pop minStack if the removed value was the minimum
        if (!minStack.isEmpty() && minStack.peek().equals(popValue))
            minStack.pop();
    }

    public int top() {
        return stack.peek();
    }

    public int getMin() {
        return minStack.peek();
    }
}

push: always push to both

minStack size == stack size
Pattern to remember
1. push → if (empty || val <= peek()) minStack.push(val)
2. pop → if (peek().equals(popValue)) minStack.pop()
3. Use .equals() not == — Integer reference equality fails outside -128..127
4. getMin → minStack.peek()
Key Insight
minStack is a shadow stack that records "what is the minimum of everything below me (inclusive)" at each level.
push(-2): stack=[-2]       minStack=[-2]     (-2 ≤ empty → push)
push(0) : stack=[-2,0]     minStack=[-2]     (0 > -2 → skip)
push(-3): stack=[-2,0,-3] minStack=[-2,-3]  (-3 ≤ -2 → push)
pop(-3) : stack=[-2,0]     minStack=[-2]     (-3 == peek → pop both)
pop(0) : stack=[-2]       minStack=[-2]     (0 != peek → skip minStack)
minStack is smaller — only stores values that were ever the minimum. After popping -3, getMin() instantly returns -2.
