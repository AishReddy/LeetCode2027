20. Valid Parentheses

LeetCode Easy — Stack

easy O(n) time  |  O(n) space
Problem

Given a string s containing only '(' ')' '{' '}' '[' ']', determine if the input string is valid. A string is valid if every open bracket is closed by the same type in the correct order.

⚡ Key insight: use a Stack. Push open brackets. On a close bracket, pop and check it matches. If stack is empty at the end → valid.
Approach — Stack
1
Open bracket '(' '{' '[' → push onto stack.
2
Close bracket ')' '}' ']' → if stack is empty or top doesn't match → return false. Otherwise pop the top.
3
End of string: return stack.isEmpty(). Any leftover open bracket means invalid.

Complexity Analysis
Time Complexity
O(n)
Single pass through the string. Each character is pushed or popped at most once.
Space Complexity
O(n)
Stack holds at most n/2 open brackets in the worst case e.g. "(((((".
Java Solution
class Solution {
    public boolean isValid(String s) {
        Stack<Character> stack = new Stack<>();

        for (char c : s.toCharArray()) {
            // open bracket → push
            if (c == '(' || c == '{' || c == '[') {
                stack.push(c);
            }
            // close bracket → check top matches
            else {
                if (stack.isEmpty()) return false;
                char top = stack.pop();
                if (c == ')' && top != '(') return false;
                if (c == '}' && top != '{') return false;
                if (c == ']' && top != '[') return false;
            }
        }
        return stack.isEmpty();
    }
}
3 things to remember
1. Open → stack.push(c)
2. Close → if (stack.isEmpty()) return false then pop and match
3. End → return stack.isEmpty()
Key Insight
The stack mirrors the nesting structure. Every open bracket "waits" on the stack for its matching close. The most recently opened bracket must be the first to close — LIFO.

Two failure cases:
"([)]" → top is '(' but close is ']' → mismatch
"(((" → stack not empty at end → unclosed brackets
