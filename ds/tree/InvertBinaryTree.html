Invert Binary Tree

Recursive pre-order DFS — swap children at every node

easy O(n) time O(h) space
Problem

Given the root of a binary tree, invert it in-place and return its root. Inverting means every node's left and right children are swapped, applied recursively at every level.

⚡ Key insight: inverting a tree = swapping left ↔ right at every node. The problem is self-similar — the same one-line swap applies at every level. Recurse into both children after the swap.
3-step recursive approach
1
Base case — if root == null, return null immediately. Handles empty trees and leaf children.
2
Swap — save root.left in temp, assign root.left = root.right, then root.right = temp. Current node is now inverted.
3
Recurse — call invertTree(root.left) and invertTree(root.right) to invert both subtrees. Return root.

Pre-order: swap current node before recursing. Post-order (swap after) also works — the final result is identical. Pre-order is more intuitive.
Full Java solution
class Solution {
    public TreeNode invertTree(TreeNode root) {
        if (root == null) {
            return null;                    // base case — leaf child or empty
        }
        // swap left and right children
        TreeNode swap = root.left;
        root.left  = root.right;
        root.right = swap;

        invertTree(root.left);              // invert left subtree
        invertTree(root.right);             // invert right subtree

        return root;
    }
}
Why pre-order?
Swap the current node first, then recurse into children. Post-order (recurse first, then swap) is equally valid — the final tree is the same either way.
Iterative BFS alternative
Use a queue: enqueue root → dequeue node → swap children → enqueue non-null children. Same O(n)/O(w) — avoids deep call stacks on skewed trees.
Complexity
Time
O(n)
Every node visited exactly once. Each visit does O(1) work (one swap + two recursive calls).
Space
O(h)
Call stack depth = tree height h. Balanced tree → O(log n). Skewed tree (worst case) → O(n).
