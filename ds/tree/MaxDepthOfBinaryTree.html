Maximum Depth of Binary Tree

Recursive post-order DFS — max(left, right) + 1

easy O(n) time O(h) space
Problem

Given the root of a binary tree, return its maximum depth — the number of nodes along the longest path from root to the farthest leaf node.

Tree:
   3
  / \
 9  20
    / \
   15  7

Output: 3  (3 → 20 → 15 or 3 → 20 → 7)
⚡ Key insight: the depth of any node = max(depth(left), depth(right)) + 1. The +1 counts the current node. Base case: null node has depth 0.
Post-order DFS approach
1
Base case — if root == null, return 0. A null node contributes zero depth.
2
Recurse both sides — compute left = maxDepth(root.left) and right = maxDepth(root.right). Each call returns the depth of that subtree.
3
Combine — return Math.max(left, right) + 1. Take the deeper subtree and add 1 for the current node.
✓ Post-order means: recurse left → recurse right → process current node. Results bubble up from leaves to root. Leaves return 1 (null children return 0, so max(0,0)+1 = 1).

Full Java solution
class Solution {
    public int maxDepth(TreeNode root) {
        if (root == null)
            return 0;                   // null node = 0 depth

        int left  = maxDepth(root.left);  // depth of left subtree
        int right = maxDepth(root.right); // depth of right subtree

        return Math.max(left, right) + 1; // deeper side + current node
    }
}
Why post-order?
You need both children's depths before you can compute the current node's depth. So recurse first, compute last — that's post-order. Pre-order wouldn't work here.
One-liner form
Can be written as:
if (root == null) return 0;
return 1 + Math.max(
  maxDepth(root.left),
  maxDepth(root.right));
Invariant — what each call returns
maxDepth(null) → 0
maxDepth(leaf) → max(0,0)+1 = 1
maxDepth(any node) → longest path from that node to a leaf, inclusive
Complexity
Time
O(n)
Every node visited exactly once. Each visit does O(1) work (one max + one add). n = total nodes.
Space
O(h)
Call stack depth = tree height h. Balanced: O(log n). Skewed (worst case): O(n).
BFS (level-order) alternative: use a queue, count levels. O(n) time, O(w) space where w = max width. For wide trees this can be worse than recursive O(h). Recursive is simpler and usually preferred.
